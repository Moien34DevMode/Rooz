# روز — برنامه‌ریز شخصی

یک نمونه‌ی اولیه‌ی فارسی و راست‌چین برای برنامه‌ریزی شخصی. دکمه‌ی DO مسیر ساخت هدف‌های بلندمدت، هدف‌های میان‌مدت، کارهای کوتاه‌مدت و روتین‌ها را باز می‌کند. نمای روز، فعالیت‌ها را روی ساعت مرکزی نشان می‌دهد و TODOها و یادداشت روز را کنار هم نگه می‌دارد. برنامه کاملاً فرانت‌اند است و به سرور یا متغیر محیطی نیاز ندارد.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه‌ی انتشار و پیش‌نمایش آن:

```bash
npm run build
npm run preview
```

## معماری

- `src/domain/` مدل‌های مستقل از رابط کاربری برای هدف‌ها، کارهای کوتاه‌مدت، یادداشت‌ها و قرارداد repositoryها را نگه می‌دارد.
- `src/services/` منطق کاربردی را روی قراردادها قرار می‌دهد؛ React فقط با سرویس planner کار می‌کند.
- `src/repositories/` پیاده‌سازی فعلی قراردادها با ذخیره‌سازی محلی را دارد.
- `src/storage/localDatabase.ts` پیکربندی Dexie و پایگاه داده‌ی IndexedDB را نگه می‌دارد. هدف‌ها، کارها، بازه‌ها، یادداشت و ترجیح تقویم بعد از بارگذاری مجدد باقی می‌مانند.
- `src/features/tasks/DoTaskDialog.tsx` فرم DO و گزینه‌های جداگانه‌ی هدف بلندمدت، میان‌مدت، کار مشخص و روتین را دارد. `taskCalculations.ts` وقوع روتین‌ها و پیشرفت وزنی هدف‌ها را از داده‌های اصلی محاسبه می‌کند.
- `src/features/calendar/` تبدیل تاریخ، نمایش تقویم و viewهای هفتگی، ماهانه و سالانه را مدیریت می‌کند. کلید تاریخ‌ها ISO میلادی است؛ تقویم شمسی یا میلادی فقط نمایش و حرکت تقویم را تعیین می‌کند.
- `src/features/daily-view/ClockPlanner.tsx` ساعت SVG و مسیر مارپیچی پیوسته‌ی ۲۴ ساعته را برای بازه‌ها و کارهای زمان‌دار رسم می‌کند. مسیر از نیمه‌شب آغاز می‌شود، پس از یک دور به ظهر می‌رسد و پس از دور دوم در نیمه‌شب بعد پایان می‌یابد.
- `src/styles/` توکن‌های طراحی و چیدمان واکنش‌گرا را نگه می‌دارد.

برنامه برای کاربران جدید خالی شروع می‌شود و هیچ داده‌ی نمونه‌ای ساخته نمی‌شود. داده‌های ذخیره‌شده‌ی کاربران قبلی دست‌نخورده می‌مانند. هدف‌ها و کارهای جدید از DO ساخته می‌شوند.

روتین‌های زمان‌دار می‌توانند از نیمه‌شب عبور کنند؛ مثلاً بازه‌ی ۲۳:۰۰ تا ۰۷:۰۰ تا نیمه‌شب در روز شروع و از نیمه‌شب تا ۰۷:۰۰ در روز بعد دیده می‌شود. ادامه‌ی بازه حتی در روزی که روتین تکرار ندارد نمایش داده می‌شود؛ وضعیت انجام هر دو بخش متعلق به روز شروع است. ساعت شروع و پایان برابر پذیرفته نمی‌شود.

برای اجرای تست‌های وقوع روتین، ادامه‌ی بازه‌های شبانه و هندسه‌ی ساعت:

```bash
npm test
```

## جایگزینی ذخیره‌سازی با API

پیاده‌سازی محلی در `src/repositories/localRepositories.ts` از قراردادهای `src/domain/repositories.ts` پیروی می‌کند. برای اتصال آینده، repositoryهای API می‌توانند همان قراردادها را اجرا کنند و در `src/services/container.ts` جای repositoryهای محلی قرار بگیرند؛ اجزای رابط کاربری و منطق هدف‌ها به Dexie وابسته نیستند. پوشه‌ی `src/api/` برای client HTTP آینده در نظر گرفته شده و اکنون هیچ درخواست شبکه‌ای انجام نمی‌شود.

هیچ داده‌ای از مرورگر خارج نمی‌شود. پاک‌کردن داده‌ی سایت در مرورگر، داده‌های محلی برنامه را نیز پاک می‌کند.
